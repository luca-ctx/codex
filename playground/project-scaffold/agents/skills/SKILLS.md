A "skill" is a family of on-demand documentation, rules, scripts, and other resources to be able to quickly onboard a predefined runbook or other action.

For example, as an AI coding agent, sometimes you will use Playwright for browser tasks, but other times even reading the instructions would be a waste of your context window.

To solve this, we have enumerated pre-defined skills that you can load on demand. Just list the directories here to see them. If you are asked to do a task, read the appropriate document (skills/{skill_name}/skill.md). The other resources likely don't need to be read unless you encounter issues or the main skill file asks you to.
